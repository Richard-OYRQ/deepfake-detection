# DeepFake 检测实践项目

基于「多模态大模型 + OpenCV 传统视觉特征」融合路线的深度伪造（换脸）视频检测系统。本项目为课程实践项目，围绕《鉴伪小组学习计划文档》选题一（数据集构建）与选题二（大模型检测）展开，目标检测准确率 85% 及以上。

## 项目简介

- **检测主体**：千问 qwen3-vl-plus 视觉语言模型，通过结构化取证提示词（16 项检测清单）逐项输出带时间戳的证据判定
- **客观锚点**：OpenCV 实现的 CV 特征体系——面颈纹理密度热力图、清晰度剖面、物理一致性 z 子分（phys）、稳定先验相似度
- **判定流程**：1 票初筛 → 控方/辩护对抗复检（3 票对称投票）→ 三分类终裁（伪造 / 无伪造 / 存疑）
- **融合规则**：`phys≥0.55 ∨（伪造票≥3 ∧ 先验≥0.56）→ 伪造`，特征缺失样本一律存疑

## 核心结果（2026-10 留出复测）

| 评估口径 | 规模 | 检出 | 误报 | 总正确率 |
|---|---|---|---|---|
| 拟合集自评 | 40 条 | 16/20（80.0%） | 2/20（10.0%） | 85.0% |
| 留出复测（数据修复前） | 160 条 | 43/80（53.8%） | 17/80（21.2%） | 66.25% |
| 留出复测（数据修复后） | 160 条 | 47/80（58.8%） | 19/80（23.8%） | **67.5%** |
| 5 折交叉验证 | 200 条池化 | 63.0% | 30.0% | 66.5% |

> 结论：三信号（伪造票/先验/phys）规则族上限约 66–67%；n=40 拟合存在乐观偏差。下一阶段按老师指导转向**自训小模型 + 大数据集**路线（学习计划选题三）。

## 数据集

| 数据集 | 规模 | 说明 |
|---|---|---|
| 自建标注基准集 | 200 条（真实 100 + 伪造 100） | 伪造由 faceswapvideo.io（inswapper 系消费级换脸，与 FaceFusion 同源）生成 |
| 自建留出集 | 160 条（真实 80 + 伪造 80） | 与基准集零重叠，冻结评估专用 |
| 外部评测集 | 2616 条（真实 550 + 伪造 2066） | 主体为 FaceForensics++ c23 抽样：第一代换脸 676（Deepfakes 226 / FaceSwap 225 / DeepFakeDetection 225）、重演类 632（Face2Face 324 / NeuralTextures 308）、第二代 558（FaceShifter）、早期社区批次 200（待溯源） |
| 配对基准集 | 14 对 1080P | FaceFusion 自生成，配对对照实验 |

> 视频数据不入库；标注规则见下文。训练注意：外部集的分辨率与伪造家族相关（如 DeepFakeDetection 全为 1080p），M1 数据管线需统一输入尺寸并打乱该关联，防止模型学到分辨率捷径。

## 目录结构

```
deepfake-detection/
├── src/            # 检测系统核心代码（client / processor / preprocessor / formatter / config）
├── prompts/        # 提示词版本存档（初版自由格式 → 14 项 / 16 项结构化清单）
├── analysis/       # 分析脚本（融合 / 消融 / 留出复测 / 5 折交叉验证）
├── docs/           # 报告与文档（中期材料、提示词工程优化过程等）
├── data/           # 标注说明与特征表（视频文件不入库）
├── archive/        # 历史实验脚本
├── config.example.yaml   # 无密钥配置模板（复制为 config.yaml 并填入密钥即可运行）
└── README.md
```

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 准备配置（config.yaml 已被 .gitignore 排除，不会误提交密钥）
copy config.example.yaml config.yaml   # 填入你的 DashScope API key

# 3. 将待检测视频放入 videos/ 目录，运行
python main.py
```

配套工具：

- `export_evidence.py` — 导出证据图样例（纹理热力图 / 清晰度剖面 / 事件帧）
- `analyze_self160.py` — 160 条留出集融合规则复测
- `newfeat_extract.py` — 第四信号特征提取（rPPG / 频域 / 唇同步，纯 CV 无 API 调用）
- `download_bench1100.py` / `download_bench_firstgen500.py` / `download_bench_rest1000.py` — 外部评测集下载工具（FF++ c23 远程抽样，含限流退避与连接超时）

## 数据标注规则

- 文件名**纯数字** = 真实视频；**F 开头** = 伪造视频
- 标签仅用于结果分析与评估，**检测流程中禁止使用标签**
- 数据集仅用于学术研究，遵守《个人信息保护法》与相关平台协议；视频数据与检测输出不入库

## 提示词工程（五版迭代）

自由格式（V1）→ 14 项结构化清单（V2，21 项精简）→ 对抗式双提示词（V3，控方/辩护人）→ 领域知识注入（V4，美颜辨析 + 软硬证据分层 + 物理不可能性证据）→ 多模态证据注入（V5，先验 P + 事件证据图 + CV 核验块）。详见 `docs/提示词工程优化过程.docx`。
